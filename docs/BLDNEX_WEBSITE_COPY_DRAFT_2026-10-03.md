## 12. 검토 회신 안내

원고의 ID와 바꿀 문장을 알려주시면 수정본을 만들 수 있습니다.

예: `H01 한글 제목 승인 / A04 공유 방식 문구 수정 / P05는 공개 준비 유지 / Q03 회사명 선택 승인 / F07 유지보수 별도 협의 유지`.

전체 승인 시에도 제품 검수·개인정보 입력값처럼 별도 확인이 표시된 항목은 실제 확인 후 공개합니다. 이번 문서 작성으로 새 운영 조건이나 제품 출시 상태가 확정되는 것은 아닙니다.
