# BLDNEX Wiki Memory

이 디렉터리는 BLDNEX 웹사이트 프로젝트의 지속적인 작업 맥락을 보관하는 위키 메모리입니다.
새 작업을 시작할 때는 이 문서를 먼저 읽고, 작업이 끝나면 결정·구조·로드맵 문서를 갱신합니다.

## 메모리 운영 규칙

- 확정된 사실은 `context.md` 또는 `decisions.md`에 기록합니다.
- 구현 구조가 바뀌면 `architecture.md`를 같은 작업에서 갱신합니다.
- 추측이나 아이디어는 `roadmap.md`에 `검토 필요` 상태로 남깁니다.
- 상세 카피와 섹션 설계는 기획 원문에 두고, 이 디렉터리에는 작업에 필요한 요약과 링크만 둡니다.
- 날짜가 중요한 결정에는 `YYYY-MM-DD`를 붙입니다.
- 제안·카피 문서는 작성 당시의 검토 메모를 포함합니다. 최신 적용 여부는 문서 상단 상태와 결정 기록을 우선하며, 업데이트 진행 지시를 미제공 운영값이나 제품 상태의 사실 확인으로 확대하지 않습니다.

## 빠른 시작

1. [프로젝트 맥락](context.md)을 읽습니다.
2. [현재 구조](architecture.md)에서 변경 지점을 확인합니다.
3. [결정 기록](decisions.md)에 어긋나지 않는지 확인합니다.
4. 작업 후 [로드맵](roadmap.md)과 관련 문서를 갱신합니다.
