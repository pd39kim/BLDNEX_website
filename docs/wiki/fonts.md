# 웹폰트 — 서브셋 셀프호스팅

최종 갱신: 2026-10-05

문의 기능 추가 후: 추출 대상에 번들 `.js`의 동적 오류/완료 문구도 포함했습니다. 입력창과 관리자 원문은 사용자 임의 문자를 표시하므로 시스템 폰트를 사용합니다. 아래 수치는 기존 폰트 전환 당시 기록이며 현재 수치는 매 빌드 결과를 기준으로 합니다. 외부 요청 0건은 폰트/홈 기준이고 활성 문의의 Turnstile은 별도입니다.

## 요약

웹폰트를 CDN에서 통째로 받던 방식을, **빌드할 때 실제로 쓰인 글자만 추려 자체 호스팅**하는 방식으로 바꿨습니다.

| | 변경 전 | 변경 후 |
| --- | --- | --- |
| 폰트 전송량 | 1,633,644 B | **194 KB** (94.1% 감소) |
| 홈 1회 로드 | 약 1.59 MB | **약 152 KB** |
| 서드파티 요청 | 3건 (Google Fonts ×2, jsDelivr) | **0건** |
| 폰트 출처 | CDN | 자체 서버 |

## 왜 바꿨나

`typography.css`가 Pretendard **static 전체 폰트**를 jsDelivr에서 불러오고 있었습니다. 이 파일은 한글 음절 11,172자를 전부 담고 있어 굵기 하나가 **766 KB**입니다. 본문(400)과 제목(600) 두 굵기를 쓰므로 1.5 MB가 매번 전송됐습니다.

측정해 보니 사이트가 실제로 쓰는 글자는 **한글 402자를 포함해 501자**뿐이었습니다. 전체의 96%를 받아 놓고 쓰지 않던 셈입니다.

덤으로 Google Fonts와 jsDelivr가 방문자 IP를 받아가던 것도 사라져, 개인정보처리방침의 국외 이전 항목에서 두 줄을 지울 수 있었습니다.

## 어떻게 동작하나

```
pnpm build
  └─ astro build                      dist/ 에 HTML 생성
  └─ node scripts/subset-fonts.mjs    dist/ 의 HTML에서 글리프 추출 → 서브셋 생성
```

1. `dist/**/*.html`과 `dist/**/*.js`를 읽어 쓰인 글자를 모읍니다. JS 유니코드 escape도 해제합니다.
2. `assets/fonts-src/`의 원본 폰트에서 그 글자만 남겨 woff2로 만듭니다.
3. `dist/assets/fonts/`와 `public/assets/fonts/`에 씁니다.

**내용을 수정해도 사람이 할 일은 없습니다.** 빌드할 때마다 글리프 집합이 다시 계산됩니다.

### 글리프 추출 규칙 — HTML 원문 전체

본문 텍스트만 추출하면 안 됩니다. 처음 그렇게 만들었다가 **20자를 놓쳤습니다**:

| 놓쳤던 글자 | 출처 |
| --- | --- |
| `홈` | `aria-label="BLDNEX 홈"` — **속성값** |
| `푸` | `aria-label="푸터 메뉴"` — **속성값** |
| `못` | `'메일 앱이 열리지 못…'` — **인라인 `<script>` 문자열** |

그래서 `collectGlyphs()`는 태그를 제거하지 않고 **HTML 원문을 그대로 훑은 뒤 HTML 엔티티만 해제**합니다. 태그명과 클래스명이 섞여 들어가지만 전부 ASCII라 결과 크기에 영향이 없습니다.

## 안전장치 — 빌드를 실패시키는 검사

`scripts/check-site.mjs`가 매 빌드마다 확인합니다. 조용히 깨지는 경우를 없애는 것이 핵심입니다.

| 검사 | 깨지면 생기는 일 |
| --- | --- |
| 원본에 있던 글자가 서브셋에서 사라지지 않았는지 | 그 글자만 시스템 폰트로 떨어져 자간·굵기가 튐 |
| 폰트 스택 **합집합**이 쓰인 글자를 전부 덮는지 | 어느 폰트에도 없는 글자가 생김 |
| CSS가 선언한 family/weight마다 파일이 있는지 | 브라우저가 가짜 볼드를 합성하거나 다른 굵기를 늘여 그림 |
| CSS·HTML에 서드파티 폰트 호스트가 없는지 | 셀프호스팅이 조용히 되돌아감 |
| preload 대상 파일이 실제로 존재하는지 | 404 preload |

라틴 폰트(DM Sans·Inter Tight)에 한글이 없는 것은 **정상**입니다. 폰트 스택이 역할을 나눠 맡으므로, 폰트별로는 "원본이 그릴 수 있던 글자 중 빠진 것"만 봅니다.

검사가 실제로 동작하는지는 서브셋을 일부러 좁게 만들어 확인했고, 빠진 글자를 모두 나열하며 실패했습니다.

## 검증 결과

전체 페이지를 CDN 폰트 / 서브셋 폰트로 각각 렌더해 비교했습니다.

| 페이지 | 렌더 크기 | 서브픽셀 차이 |
| --- | --- | --- |
| home | 1425×5664 (before/after 동일) | 0.512% |
| about | 1425×4015 (동일) | 0.700% |
| contact | 1425×2482 (동일) | 0.588% |
| privacy | 1425×5336 (동일) | 0.219% |

**전체 높이가 네 페이지 모두 1픽셀도 다르지 않습니다.** 폰트 메트릭이 조금이라도 달랐다면 줄바꿈이 변해 높이가 달라집니다. 즉 레이아웃은 동일합니다.

남은 0.2~0.7%는 글자 테두리의 안티앨리어싱 차이입니다. 라틴 폰트를 Google의 미리 만든 static 파일 대신 **가변폰트에서 굵기를 인스턴싱**해 만들기 때문에 외곽선이 극미하게 다릅니다. 확대 비교에서 글자 모양·너비·위치는 구분되지 않았습니다.

## 자주 묻는 것

**내용을 수정하면 서브셋을 다시 만들어야 하나요?**
아니요. `pnpm build`에 묶여 있어 자동입니다. 수동으로 만들어 커밋하는 방식이었다면 매번 다시 해야 했을 것입니다.

**글씨 크기를 바꿔도 되나요?**
됩니다. 서브셋은 *글자(글리프)* 를 덜어내는 작업이지 크기와는 무관합니다. 글리프는 벡터 외곽선이라 어떤 크기로도 깨짐 없이 커지고 작아집니다. 브라우저 확대, 사용자 기본 글자 크기 설정도 영향 없습니다.

**글씨 굵기를 바꾸면요?**
이쪽은 주의가 필요합니다. 현재 파일이 있는 조합은 아래 6종뿐입니다. 없는 굵기를 쓰면 브라우저가 **가짜 볼드를 합성**해 뭉개져 보입니다. 그래서 CSS가 선언한 굵기에 파일이 없으면 빌드가 실패하도록 해 뒀습니다. 새 굵기가 필요하면 `scripts/subset-fonts.mjs`의 `faces`에 추가하고, 원본이 없으면 `scripts/fetch-fonts.mjs`에도 추가합니다.

**사용자 환경에 따라 다르게 보이나요?**
woff2는 2016년 이후 모든 주요 브라우저가 지원합니다. `font-display: swap`과 `sans-serif` 폴백이 있어, 폰트를 못 받아도 글자가 사라지지 않고 시스템 폰트로 읽힙니다. 오히려 외부 CDN의 DNS·TLS 왕복이 사라져 느린 회선에서 더 빨리 뜹니다.

## 파일

| 경로 | 역할 | git |
| --- | --- | --- |
| `assets/fonts-src/` | 원본 폰트 + OFL 라이선스 전문 | 커밋함 |
| `scripts/fetch-fonts.mjs` | 원본 내려받기 (`pnpm fonts:fetch`) | 커밋함 |
| `scripts/subset-fonts.mjs` | 서브셋 생성 (빌드가 자동 실행) | 커밋함 |
| `src/styles/typography.css` | `@font-face` 선언 | 커밋함 |
| `dist/assets/fonts/` | 배포본 | 생성물 |
| `public/assets/fonts/` | dev 서버용 사본 | **gitignore** |

원본을 저장소에 커밋해 두어 빌드 때 네트워크를 타지 않습니다. Cloudflare Pages처럼 매번 새로 받아 빌드하는 환경에서도 외부 장애에 영향받지 않습니다.

`public/assets/fonts/`는 `astro dev`가 서빙할 사본입니다. 글리프 목록이 빌드된 HTML에서 나오므로 서브셋은 빌드 뒤에 돌고, 이 사본 덕분에 **다음 `pnpm dev`부터** 개발 화면도 같은 폰트로 보입니다. 저장소를 처음 받은 직후에는 `pnpm build`를 한 번 돌려야 합니다.

## 라이선스

세 폰트 모두 SIL Open Font License 1.1입니다. 서브셋 파일을 배포하므로 라이선스 전문을 함께 제공해야 하며, `scripts/subset-fonts.mjs`가 `OFL-*.txt`를 폰트와 같은 디렉터리에 복사합니다.

- Pretendard — 길형진 (orioncactus)
- Inter Tight, DM Sans — Google Fonts (OFL)

## 폰트 원본 갱신

상위 버전이 나왔을 때만 수동으로 합니다. 1년에 한두 번이고, 하지 않아도 사이트는 정상 동작합니다.

```sh
pnpm fonts:fetch   # assets/fonts-src/ 갱신
pnpm test          # 빌드 + 전체 검사
```
